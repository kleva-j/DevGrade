Question review

When does React batch state updates in event handlers?

React 18 batches all state updates in event handlers, timeouts, and promises automatically. Your answer correctly identified automatic batching.

What is the correct way to update state based on its previous value?

Using the functional form setCount(prev => prev + 1) ensures each update sees the latest state, preventing lost updates.

Which hook is the right tool for syncing with an external system?

useEffect is the correct choice for synchronising with external systems. You correctly identified it.

How do you cancel a fetch inside a useEffect?

The correct approach is to use an AbortController and call abort() in the cleanup function. You selected "return a boolean flag" which doesn't cancel the network request.

What does React.memo do?

Correct — React.memo skips re-rendering a component if its props haven't changed (shallow equality check).

When should you use useCallback?

Correct — stabilise a function reference to prevent unnecessary child re-renders when it's passed as a prop.

What triggers a component to re-render?

State changes, prop changes, and context value changes all trigger re-renders. You missed context updates as a trigger.

What is the purpose of useLayoutEffect?

Fires synchronously after the DOM mutations, before the browser paints. Correct — use it when you need to measure or mutate the DOM before the user sees it.
